# Pokemon Application
Ett React-gränssnitt där man kan välja en Pokemon i en lista och se information om den. Datan hämtas från PokeAPI.

## Funktioner
- Knapp för att starta appen
- Hämtar de 151 första Pokemon och visar dem i en dropdown
- Visar namn, bild, typer, vikt och längd för vald Pokemon

## Köra projektet
npm install
npm run dev

Öppna sedan adressen som visas i terminalen (t.ex. http://localhost:5173).
